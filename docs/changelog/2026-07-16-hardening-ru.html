Что сделано

Dedicated Megatron receipt

Pytest больше не принимает случайный namespace или ambient source tree. Выбранный Megatron должен быть реальным Git checkout с чистым состоянием и exact commit receipt. Альтернативный root, не совпадающий с receipt, требует отдельный CPPMEGA_MEGATRON_COMMIT.

  • conftest.py
  • scripts/env/cppmega_env.py
  • docs/environment.md

Self-hosted runner contract

macOS lane указывает на /Volumes/external/sources/.venvs/cppmega.source/bin/python. Каждый lane subprocess получает PYTHONNOUSERSITE=1 и PYTHONSAFEPATH=1, а portable profile объявлен в lane JSON, а не спрятан в коде.

  • configs/ci/hosts.json
  • configs/ci/lanes.json
  • scripts/ci/repository_runner.py
  • self-hosted workflow

Локальный prompt graph и C++ generation

Graph/indexer loader теперь принадлежит этому checkout и восстанавливает исходный объект sys.path. H200 eval по умолчанию не тянет indexer из MLX checkout. Formatter resolution использует PATH, Xcode и LLVM Homebrew без ослабления compile gate; broken/timeout xcrun даёт контролируемый fallback. Restore Megatron bundle CLI также работает при direct execution и safe-path.

  • cppmega/prompt_graph_index.py
  • cppmega/data/prompt_graph_index.py
  • H200 generation eval
  • compile/format gate
  • restore bundle CLI

Current RSS memory guard

Вместо исторического ru_maxrss используются live probes: procfs, psutil и Unix ps. Если ни один probe не работает, watchdog завершается fail-closed.

  • scripts/data/memory_guard.py
  • scripts/nanochat_data/memory_guard.py

Package boundary

Tracked egg-info пересобран из текущего pyproject.toml: Python >=3.11, optional data dependency datasketch==1.10.0. Setuptools discovery ограничен cppmega и cppmega.*; wheel содержит runtime contracts domain_schema_v1.json, tokenizer.json и tokenizer_contract_v1.json, но не публикует namespace cppmega_mlx.

Dependabot: review 17 июля 2026

Alert GHSA-rrmf-rvhw-rf47 закрыт заменой vulnerable reproducer pin torch==2.12.0.dev20260410+cu132 на стабильный CUDA-релиз torch==2.13.0+cu132. Тот же стабильный pin теперь используется в STACK.lock, CUDA Docker и self-hosted wheel workflow; активные H200/B200 Modal-образы больше не разрешают nightly. cppmega.mlx уже имел стабильный torch 2.13.0 в uv.lock, а optional Path C теперь явно требует именно этот релиз. Исторические отчёты о старых nightly-прогонах сохранены как история, но текущий production/reproducer contract больше не зависит от dev-сборки.

Остаточные риски

Локальный Mac не даёт доказательства H200/CUDA kernel runtime. Self-hosted workflow и contracts проверены, но GPU receipt должен быть получен на выделенном CUDA runner.

Warnings Transformer Engine/Apex в dedicated Mac environment ожидаемы и не считаются GPU результатом.

Repo-wide Ruff ещё содержит 202 legacy violations в нетронутых файлах; все Python-файлы production diff проходят pinned changed-file Ruff.

Для CUDA wheel ABI требуется пересобрать custom Transformer Engine и остальные C++/CUDA wheels после смены torch pin; локальный Mac не заменяет этот self-hosted GPU receipt.

Отчёт сгенерирован из текущего source tree; ссылки указывают на ветку hardening, а не на старые review notes.
