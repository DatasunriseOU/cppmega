1. Короткий итог

  1. cppmega теперь владеет Megatron/CUDA runtime и полным root-local data path: source, clang index, parquet, audit, graph sidecars и Megatron conversion.
  2. cppmega.mlx остаётся Apple Silicon runtime, Path C/Metal исследовательским контуром и визуальным конструктором/инспектором.
  3. KSH и Python расширяют существующий v1 на reserved IDs 245-248, без изменения tokenizer vocabulary и без перенумерации.
  4. Detours прошёл реальный root-only end-to-end путь с fail-closed audit и 31 дополнительным sidecar channel.
  5. CASE5 v4 содержит 1 411 702 081 trained tokens и 7 178 schedule-valid полных шагов.
  6. CASE5 v7 snapshot partial: 153 090 795 trained tokens, 776 schedule-valid steps и 77 done / 11 failed. Run использует старый pinned runtime 1ba36f7, не текущий MLX HEAD 12610eb.
  7. A2 DB очищена от libiberty, но множественные overloads подтверждают, что qname не уникален.
  8. На exact root commit 2b5dd3d H200 DSA suite дал 7 passed, final gate - 11 passed; writer/reader receipt: 46 docs, 45 257 valid, 45 063 trained, 20 aligned sidecars, 11 graph CSR.
  9. Source-local FIM/AST-FIM, per-document IFIM binding и partial commit rows закрыты на canonical MLX head; открыты pinned v7 rerun, Xbox provenance и root environment packaging gap.

  • Source, output, repo-list и tokenizer paths передаются явно.
  • Revision guard фиксирует exact commit и relevant dirty scope.
  • Root entrypoints не используют sibling checkout defaults.
  • FP8/DSA backend errors fail-loud, без автоматической MLX-подмены.
  • Megatron output публикуется generation directory + atomic current pointer.

Ключевые файлы: source conveyor · Megatron converter · entrypoint tests.

6. Роль MLX runtime и визуального слоя

  1. Apple Silicon runtime: MLX eager/compiled smokes, checkpoints и локальные model-contract checks.
  2. Metal/TileLang research: Path C planner, generated kernels, Mamba3/MLA/DSA fusion и честные unsupported boundaries.
  3. Visual Builder: model graph, tokenizer spans, parquet/domain/graph inspection и debugging state.

Локальные поверхности: DataInspector · tokenizer RPC · Path C schedules.

MLX pass не доказывает CUDA/TE или distributed Megatron. H200 component smoke, в свою очередь, не заменяет локальные macOS generation/eval/compile gates.

13. FIM/AST-FIM: eligibility и physical identities

Основной source-local contract gap закрыт в MLX commit 12610eb. Старый CASE5 v7 conveyor всё ещё pinned на 1ba36f7 и не считается автоматически перепроцессированным.

EligibilityAwareTaskMixer теперь допускает mixed-source context, но выбирает FIM/AST-FIM/recovery middle только внутри contiguous (source_doc_id, source_identity_id) run. IFIM instruction привязывается к logical document через source_ifim_instruction_token_ids, а не broadcast-ится на весь packed row.

СлойЧто уже естьПочему receipt ещё не закрыт
EligibilitySource-local middle, AST chunks, recovery spans and document-local IFIM bindingLegacy unit packets without sidecars remain backward-compatible API; production rows still require the typed sidecar boundary
MaterializationProduction materializer independently validates transformed middle and remaps provenance registryCorpus-level acceptance still needs a new pinned v7/v8 rerun
Tests201 passed; 60-document artifact and root converter receiptsOld v7 failed units must be rerun with the new runtime

Итого: source-local safety и document-local IFIM binding приняты локально. Для corpus-level acceptance нужен отдельный pinned rerun, потому что действующий v7 запуск использует старый runtime и его 77/11 snapshot.

Дополнительные источники: data/parquet/Megatron review · objective mixture contract.
