Вердикт

Старые Megatron prefixes и старые graph-route checkpoints не являются доказательством корректности. В landed parquet была реальная утечка между документами, а в прежнем training path были неполные sidecars, неверная система координат graph edges и неработающие градиенты side embeddings. Исправленный frozen snapshot содержит достаточно данных для следующего meaningful run, но production objective mixer и graph-conditioned inference ещё не собраны в один надёжный путь.

Что именно мы строим

CppMega — C/C++ software world model, а не general-purpose chat model. Основной stream — source, templates/macros, comments/docstrings и clang semantics. Commit + integrated PR задают реальные pre/diff/post переходы.

Build systems, shells, diagnostics и позднее embedded SQL остаются отдельными delimiter-bounded domains со своими parsers, roles и routes; они не маскируются под comments.

Dense GQA видит полный контекст и получает deterministic AST/def-use/type/call/include/build/diagnostic priors. I_neural + βS_graph включается как DSA selector после dense graph training, главным образом для 32k–128k.

Stable loop моделирует edit→build→diagnostic→test trajectories. Decode заканчивается не текстом, а reparse, format, compile, link, executable oracle и verified feedback.

Dense GQA видит все токены: graph routes там добавляют детерминированный structural prior, а не вырезают контекст. DSA нужен позже, когда 32k–128k делают dense attention экономически дорогим.

План генерации C/C++

  1. Развести prompt contracts: source-prefix-with-docstring, настоящий docstring/signature-only, FIM и IFIM должны иметь разные labels и receipts.
  2. Строить sidecars до decode: parser + clang adapter для prompt; repo repair получает dependency blocks и call/type/def-use/build/diagnostic routes.
  3. Не притворяться с suffix sidecars: baseline может быть zero, production обязан incremental parse или периодический full reparse.
  4. Форматировать и проверять: decode whitespace, reject metadata tokens, clang-format, clang parse, compile, link, executable oracle, sanitizer/timeout classification.
  5. Считать pass@k и leakage: pass@1/5/10, repo/commit/file/function/content hashes против frozen training manifest.
  6. Эвалы локально: checkpoint conversion может идти на H200, generation/compile gate по умолчанию выполняется на local macOS.

Текущие старые receipts дают 0/4 compile и на CUDA, и после MLX conversion. Низкий teacher-forced PPL у causal checkpoint не доказывает способность генерировать компилируемый код.

Milestone checkpoints: 50M, 5B, 8.5B, 10.5B, 13.2B trained tokens; rolling каждые 250M с optimizer, RNG, scheduler и exact data cursor. Пять context buckets — один curriculum, не пять независимых моделей.

Frozen bundle даёт 4.124B causal loss targets. Граница S1=5B — это примерно 1.21 effective passes с FIM/AST-FIM/IFIM transforms, а не 5B уникальных source tokens. Финальные 13.2B близки к порядку 20 tokens/parameter для текущей ~714.7M модели; новые conveyor данные должны добавлять разнообразие.
